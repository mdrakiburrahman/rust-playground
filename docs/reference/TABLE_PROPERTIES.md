# Table properties

Generated by `nx run arrowcol-props:generate-docs`; do not edit this table by hand.

Table TBLPROPERTIES override process defaults, which override the defaults below. Unknown `arrowcol.*` keys are rejected with a suggestion. Other Delta/vendor keys are preserved. Boolean values are `true`/`false`; byte sizes accept B, KB/MB/GB and KiB/MiB/GiB; durations accept integer milliseconds or units (including Spark `interval 7 days`). Column lists are comma-separated and unique.

**Safety:** PURGE removes logical data. VACUUM deletes physical files; properties never bypass its seven-day minimum or retained-tombstone safety checks. Schema-specific column validation happens when the writer opens the table.
